## 2. Общий формат запроса

**Endpoint:** `https://api.novaposhta.ua/v2.0/json/`

**HTTP-метод:** `POST`

Данные передаются в теле запроса в формате JSON.

```json
{
  "apiKey": "твой_ключ",
  "modelName": "Address",
  "calledMethod": "getCities",
  "methodProperties": {}
}
```

## 3. Общий формат ответа

Nova Poshta API возвращает ответ в формате JSON.

Основные поля ответа:

- `success` — основной признак результата операции. Значение `true` означает, что операция выполнена успешно, а `false` — что произошла ошибка.
- `data` — данные, полученные в результате успешного запроса.
- `errors` — список ошибок, возникших при выполнении операции.
- `warnings` — дополнительные предупреждения, которые не всегда делают операцию неуспешной.
- `info` — дополнительная служебная информация об ответе.

Пример ответа:

```json
{
  "success": true,
  "data": [],
  "errors": [],
  "warnings": [],
  "info": []
}
```

HTTP-кода `200` недостаточно, чтобы считать операцию успешной. Он означает, что сервер принял и обработал HTTP-запрос. Для проверки результата операции необходимо проверить значение поля `success`.
